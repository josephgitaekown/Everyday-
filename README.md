# 일무따 복습 강화 v5

- 공식 출판사 공개 목차를 기준으로 1~60과 단원 내용 구성
- 각 과 10개 복습문제와 5개 미니 확인 문제
- 모든 정답은 선택 후 일본어 원문/히라가나 발음/한국어 뜻/해설 표시
- 15문제 완료, 12개 이상 정답일 때 복습 완료
- 오답노트에서 틀린 문제 다시 풀기, 100점 환산 점수판
- 기존 크림/코랄 UI 및 Scriptable 위젯 디자인 유지
- 기존 학습기록과 진도는 동일한 GitHub Pages 주소의 브라우저 저장소에 보관

## iPhone GitHub Pages에 업데이트
1. Safari에서 본인의 GitHub 저장소를 열고 Add file > Upload files를 선택합니다.
2. 이 폴더의 `index.html`만 선택하여 기존 같은 파일을 교체하세요.
3. Commit changes 클릭.
4. Actions에서 Pages 배포 완료 확인 후 Safari에서 새로고침.
5. Scriptable 위젯은 기존 주소가 같다면 다시 설치할 필요 없습니다.

메모: 앱 문제는 교재 본문을 복제하지 않은 자체 제작 연습문제입니다. 공개 목차의 각 과 대표 문장은 학습 기준 표시용입니다.
