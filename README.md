# 일무따 복습 노트 — GitHub Pages + Scriptable

기준: 2022년 『일본어 무작정 따라하기 완전판』(60과).

## 설치
1. ZIP 압축을 풀고 `index.html`, `manifest.webmanifest`, `icon.png` 3개를 GitHub 저장소 `mainichi-japanese` 최상위에 업로드 또는 덮어쓰기한다.
2. GitHub Settings → Pages → main / root 설정이 유지된 경우 배포된 URL에서 앱을 연다.
3. Safari 공유 → 홈 화면에 추가.
4. Scriptable 앱 → 새 스크립트 만들기 → `위젯코드_복사용.txt` 전체 붙여넣기 → '일무따 위젯' 저장.
5. 작은 Scriptable 홈 화면 위젯 추가 → 길게 누름 → 위젯 편집 → 스크립트 선택.
6. Github Pages 계정명이 다르면 위젯 상단의 APP_URL 수정.

## 책/저작권 안내
출판사 공개 목차로 검증된 1~18과 핵심 표현만 간략 표시. 19~60과는 정확한 소제목을 확증하지 못해 사용자 입력 형식으로 두었음. 출판사 원문 설명/문제/오디오는 복제하지 않음. 자체 제작 퀴즈 6개가 과별 순환됨(과별 전용 퀴즈 60세트가 아님). 출판사 공식 음성 링크로 원어민 강의 접근 가능.

## 한계
GitHub Pages 웹앱은 Scriptable 위젯과 localStorage를 공유하지 않으므로 위젯은 날짜 기반 표시이고 실제 앱 학습 진행과 동기화하지 않음. iPhone 음성 합성 음질이 나쁘면 공식 MP3를 이용. 오후 9시 알림은 단축어 앱에서 별도로 설정. 새 도메인 이동 시 기존 진도 자동 이전되지 않음.
